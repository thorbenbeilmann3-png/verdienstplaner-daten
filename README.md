# verdienstplaner-daten

Öffentliche Daten für die App **Verdienstplaner**: Gesetzeswerte, Tarife, Krankenkassen-Zusatzbeiträge, Arbeitgeber-Extras und Neuigkeiten.

- Datei: `daten.json`. Die App lädt sie über `https://raw.githubusercontent.com/thorbenbeilmann3-png/verdienstplaner-daten/main/daten.json`.
- Hier liegen **keine persönlichen Daten** und kein App-Code.
- `version` (JJJJ-MM-TT) muss bei jeder Änderung erhöht werden, sonst übernimmt die App nichts.
- Jede Neuigkeit braucht eine amtliche Quelle (`quelle`).

Alle Werte ohne Gewähr. Keine Steuer- oder Rechtsberatung.
